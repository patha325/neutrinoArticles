# Neutrino Articles

Research material for neutrino detection and direct communication studies by Sven-Patrik Hallsjö.

## Contents

- [`submarine_detection/`](submarine_detection/) — verified reference and methodological bridge to *Locating nuclear-powered submarines with antineutrinos* (2026). The canonical paper is linked to arXiv; its unpublished working source has not been reconstructed here.
- [`communication/manuscript/`](communication/manuscript/) — working draft of *Direct Neutrino Communication Through the Earth: Event-Count Scaling and Empirical Packet Benchmarks*.
- [`communication/analysis/`](communication/analysis/) — standard-library Python scoping, finite-message simulation and tests.
- [`communication/data/`](communication/data/) — benchmark, sensitivity and finite-message simulation outputs plus inverse detector-power and latency examples.
- [`communication/figures/`](communication/figures/) — vector and raster scientific figures, generated by `communication/analysis/make_figures.py`.
- [`communication/notes/`](communication/notes/) — earlier concept, model assumptions, limits and next steps.
- [`background/`](background/) — annotated bibliography and source links.

## Reproduce

```bash
python communication/analysis/model.py
python communication/analysis/tradeoffs.py
python communication/analysis/throughput.py
python communication/analysis/empirical_message.py
python communication/analysis/solar_system_scaling.py
pip install -r communication/analysis/requirements-figures.txt
python communication/analysis/make_figures.py
python -m unittest discover -s communication/analysis -p 'test_*.py'
```

The original model writes its CSV files to the analysis directory when run; the empirical packet and Solar System scripts write to `communication/data/`. The far-field calculation is deliberately optimistic: its tabulated MW is a full-duty-equivalent **energy flow carried by neutrinos**, not accelerator electrical power or achieved communications performance. The empirical packet example instead counts **proton beam energy incident on the published experimental target**; it does not transfer that receiver event mean to the far-field model.

## Research status

The communication paper is a working draft. It checks the idealized zero-background Poisson calculation against Stancil et al.'s published selected-event mean, simulates a distinct repeated-OOK/CRC finite-message protocol for the same experimental source and receiver, and explores an assumed monoenergetic far-field link. A `communication/notes/reviewer_response.md` checklist records the remaining source, flavor, detector and complete-protocol work. No submission-ready long-baseline engineering feasibility claim is made.
