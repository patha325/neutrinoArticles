# Neutrino Articles

Research material for neutrino detection and direct communication studies by Sven-Patrik Hallsjö.

## Contents

- [`submarine_detection/`](submarine_detection/) — verified reference and methodological bridge to *Locating nuclear-powered submarines with antineutrinos* (2026). The canonical paper is linked to arXiv; its unpublished working source has not been reconstructed here.
- [`communication/manuscript/`](communication/manuscript/) — first draft of *Direct Neutrino Communication Through the Earth: An Initial Quantitative Feasibility Map*.
- [`communication/analysis/`](communication/analysis/) — standard-library Python scoping calculation and tests.
- [`communication/data/`](communication/data/) — benchmark and 27-scenario outputs plus inverse detector-power and latency examples.
- [`communication/figures/`](communication/figures/) — vector and raster scientific figures, generated by `communication/analysis/make_figures.py`.
- [`communication/notes/`](communication/notes/) — earlier concept, model assumptions, limits and next steps.
- [`background/`](background/) — annotated bibliography and source links.

## Reproduce

```bash
python communication/analysis/model.py
python communication/analysis/tradeoffs.py
python communication/analysis/throughput.py
pip install -r communication/analysis/requirements-figures.txt
python communication/analysis/make_figures.py
python -m unittest discover -s communication/analysis -p 'test_*.py'
```

The model writes its CSV files to the analysis directory when run. The checked-in `communication/data/` CSVs are snapshots from the initial run. The calculation is deliberately optimistic: the tabulated MW is a full-duty-equivalent **energy flow carried by neutrinos**, not accelerator electrical power or achieved communications performance. See the manuscript for scope and limitations.

## Research status

The communication paper is a first draft. It checks the idealized zero-background Poisson decoder against the published selected-event mean from Stancil et al. (2012) and explores an assumed monoenergetic far-field link. Facility-specific flux, flavor propagation, receiver geometry, backgrounds and message-level decoding remain unmodelled. No submission-ready engineering feasibility claim is made.
