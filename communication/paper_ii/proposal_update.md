# Proposal update: benchmark results and review-driven revisions

The source-selection gate for an open benchmark is met: the DUNE TDR G4LBNF v3r5p4 FHC far-detector flux, associated GENIE charged-current cross-section table and GLoBES response inputs, a 40 kt fiducial-mass receiver, and the public 1284.9 km oscillation baseline. The supplied flux remains at its documented 1297 km reference plane; no point-source inverse-square correction is applied. The difference between the flux-plane and oscillation-baseline conventions remains a geometry-provenance item to confirm before precision use. This is a reproducible simulation benchmark, not a proposed DUNE communications operating mode.

The first-pass fold includes three-flavor matter evolution through PREM, 12-point Gaussian integration within each 250 MeV flux bin, CC interactions, and a reconstructed-energy efficiency vector used as a true-energy proxy. It gives \(2.4572\times10^{-18}\) selected \(\nu_\mu\) CC events per POT, approximately 2703 selected events per 40 kt nominal exposure-year, and a calendar-average rate of \(8.56\times10^{-5}\) events per second. The nominal annual POT convention already incorporates projected accelerator availability; the model adds no second uptime factor, but it does not resolve spills, bunch structure, or detector live-time windows. The efficiency proxy and omitted migration matrix remain the main detector-response limitation.

The revised decoder results complete the advertised PPM comparison. At equal average selected events per channel slot, the package reports OOK BER, repetition-5 BER, PPM-4/8 symbol-error probability, raw bits per slot, mean selected events per raw bit, and a conditional incident-proton beam-energy equivalent. The energy equivalent is not neutrino-carried energy or facility electrical energy. Background means 0 and 0.01 events per slot remain sensitivity cases; because symbol duration changes across the sweep, neither is a fixed physical background rate.

The rare uncoded packet result is one success in 12,000 trials: \(8.3\times10^{-5}\), with a 95% Wilson interval of \([1.5\times10^{-5},4.7\times10^{-4}]\). The figure now includes this uncertainty and a log-probability panel. Quadrature order is compared from 4 through 32 points; the 12-point result differs from the 32-point numerical reference by \(1.36\times10^{-5}\) relative. An independent SciPy matrix-exponential propagation agrees with the production eigensolver to a maximum absolute transition-probability difference of \(1.2\times10^{-13}\) over the tested energies and profiles. This is a second numerical method using the same Hamiltonian, not a direct GLoBES cross-check; an independent package/rate comparison remains open.

For the next proposal revision, the main physics task is to use the full reconstructed-energy migration response and verify the flux plane/baseline geometry from the beamline coordinates. Then add propagated flux, cross-section, oscillation, and selection uncertainties; use spill-level flux and detector live-time; and replace per-slot background sensitivities with measured background rates. A synchronization and packet protocol can then be evaluated against event timestamps. Facility-input energy analysis requires a specified accelerator operating model. Paper II supplies the conditional source-to-count channel and decoder baselines; *The Neutrino Channel: Capacity and Coding in the Few-Event Regime* remains a distinct follow-on study.
